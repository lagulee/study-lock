# 공부 잠금 (study-lock)

공부할 때 손이 가는 앱을 잠가 두고, **할 일을 끝낸 사진으로 인증해야** 풀리는 안드로이드 앱이에요.
갤럭시 S22·갤럭시 탭 S10+에서 쓰려고 만들었어요(안드로이드 10 이상). 기기마다 따로 설치하고, 기록도 기기마다 따로 남아요.

## 어떻게 동작하나요

1. **할 일**을 적어요. 예: `수학 문제집 24~27쪽 풀기`
2. **막을 앱**을 골라요. 예: 유튜브, 인스타그램, 게임
3. **집중 시작**을 누르면, 고른 앱을 열 때마다 홈으로 돌아가고 잠금 화면이 떠요.
4. 풀려면 둘 중 하나:
   - **사진 인증**: 앱이 새 4자리 숫자를 보여 줘요. 할 일을 한 종이에 그 숫자를 손으로 써서 찍으면, 폰 안의 글자 인식 AI가 숫자가 맞는지와 글씨가 충분한지(기본 30자·3줄)를 확인해요. 인터넷도, 돈도 들지 않아요.
   - **기다려서 풀기**: 정해 둔 시간(기본 20분)을 기다리면 풀려요. 급할 때 쓰는 비상구예요.

숫자는 15분마다 바뀌어서 예전 사진으로는 풀 수 없어요. 인증에 실패하면 30초 뒤에 다시 찍을 수 있어요.
집중 중에는 막을 앱을 **더 넣을 수만** 있고, 빼거나 설정을 바꿀 수는 없어요.

## 설치하기

1. 이 저장소의 [Actions](../../actions) 탭 → 가장 위의 초록색 ✅ 실행 → 아래 **Artifacts**의 `study-lock-apk`를 내려받아요.
2. 내려받은 zip을 풀면 `app-debug.apk`가 나와요. 폰으로 옮겨서 눌러 설치해요.
3. "출처를 알 수 없는 앱" 경고가 뜨면 **설정 → 이 출처 허용**을 켜고 설치해요.

같은 방법으로 새 버전을 받아 설치하면 기록과 설정이 그대로 남은 채 업데이트돼요.

## 처음 한 번만: 권한 켜기

이 앱에 필요한 권한은 **접근성** 하나예요(카메라는 기본 카메라 앱을 빌려 쓰므로 따로 묻지 않아요).
접근성 권한은 "지금 어떤 앱이 열렸는지"를 알려 주는 기능이고, 이 앱은 화면 내용을 읽지 않아요.

1. 공부 잠금 앱 첫 화면의 **접근성 설정 열기**를 눌러요.
2. **설치된 앱**(또는 "설치된 서비스") → **공부 잠금** → 켜기 → **허용**.
3. 만약 켜지지 않고 **"제한된 설정"** 창이 뜨면(인터넷에서 받은 앱이라 갤럭시가 막는 거예요):
   1. 앱 첫 화면의 **앱 정보 열기 (제한된 설정 허용)** 를 눌러요.
   2. 오른쪽 위 **⋮** → **제한된 설정 허용** → 잠금 화면 비밀번호 입력.
   3. 다시 2번으로 가서 켜요.
4. 첫 화면에 ✅ "앱 막기 기능이 켜져 있어요"가 보이면 끝이에요.

> 가끔 갤럭시가 배터리를 아끼려고 앱을 멈출 수 있어요. 잠금이 안 걸리면
> **설정 → 애플리케이션 → 공부 잠금 → 배터리 → 제한 없음**으로 바꿔 주세요.

## 설정

- **기다려서 풀 때 걸리는 시간**: 10·20·30·60분
- **사진에서 읽어야 하는 글씨 양**: 15·30·60자 (손글씨가 잘 안 읽히면 줄여요)
- **설정 앱도 잠그기**: 켜면 집중하는 동안 설정 앱과 앱 삭제 창도 막혀요. 접근성을 끄거나 앱을 지우는 꼼수를 막아 줘요.

## 알아 둘 점

- 글자 인식 AI는 **숫자와 글씨 양만** 봐요. "24~27쪽을 다 풀었는지" 같은 내용까지 판단하지는 못해요. 결국 스스로와의 약속을 도와주는 도구예요.
- "설정 앱도 잠그기"를 끈 상태에서는 접근성을 직접 꺼서 풀 수 있어요.
- 만든 사람: 직접 쓰려고 만든 개인 앱이라 Play 스토어에는 없어요.

## 개발

- Kotlin, 안드로이드 기본 화면(라이브러리 최소), 글자 인식은 Google ML Kit(한국어 모델, 기기 안에서 동작).
- `OcrCheck.kt`가 통과 여부를 정하는 순수 함수이고 `app/src/test`에 단위 테스트가 있어요.
- `main`이나 `claude/**` 브랜치에 푸시하면 GitHub Actions가 테스트 후 APK를 만들어요.
