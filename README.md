# 공부 잠금 (study-lock)

공부할 때 손이 가는 앱을 잠가 두고, **할 일을 끝낸 사진으로 인증해야** 풀리는 안드로이드 앱이에요.
갤럭시 S22·갤럭시 탭 S10+에서 쓰려고 만들었어요(안드로이드 10 이상). 기기마다 따로 설치하고, 기록도 기기마다 따로 남아요.

## 어떻게 동작하나요

1. **할 일**을 적어요. 예: `수학 문제집 24~27쪽 풀기`
2. **막을 앱**을 골라요. 예: 유튜브, 인스타그램, 게임
3. **집중 시작**을 누르면, 고른 앱을 열 때마다 홈으로 돌아가고 잠금 화면이 떠요.
4. 풀려면 둘 중 하나:
   - **사진 인증**: 시작할 때 정한 **최소 집중 시간**(기본 30분)이 지나면 인증 버튼이 열려요. 한 일(문제집·노트)을 사진으로 찍어요.
     - 설정에 **AI 키**가 없으면: 사진은 기록으로 남고 바로 풀려요.
     - **Claude 키**나 **Gemini 키**가 있으면: AI가 할 일과 사진을 비교해서 정말 했는지 판단해요. 통과 못 하면 이유를 알려 주고 30초 뒤에 다시 찍을 수 있어요.
   - **기다려서 풀기**: 정해 둔 시간(기본 20분)을 기다리면 풀려요. 급할 때 쓰는 비상구예요.

인증 사진과 AI 의견은 첫 화면의 기록(최근 30개)에서 다시 볼 수 있어요.
집중 중에는 막을 앱을 **더 넣을 수만** 있고, 빼거나 설정을 바꿀 수는 없어요.

## 설치하기

1. 이 저장소의 [Actions](../../actions) 탭 → 가장 위의 초록색 ✅ 실행 → 아래 **Artifacts**의 `study-lock-apk`를 내려받아요.
2. 내려받은 zip을 풀면 `app-debug.apk`가 나와요. 폰으로 옮겨서 눌러 설치해요.
3. 경고가 뜨면:
   - "출처를 알 수 없는 앱" → **설정 → 이 출처 허용**을 켜요.
   - Play 프로텍트 "안전하지 않은 앱" → **자세히 → 무시하고 설치**.
   - 설치 자체가 막히면 갤럭시 **설정 → 보안 및 개인정보 보호 → 자동 차단**이 켜져 있는지 보고, 설치할 때만 잠깐 꺼요.

**업데이트할 때는 앱을 지우지 마세요.** 새 APK를 받아 그냥 설치하면 "업데이트"로 깔리고 기록·설정·AI 키가 그대로 남아요.
빌드마다 같은 서명 열쇠를 쓰고 버전 번호(빌드 번호)가 계속 커지게 해 두었어요. 서명 열쇠를 잃어버릴 상황이면 빌드가 멈추고 알려 줘요(매주 한 번 자동으로 열쇠를 살려 둬요).

> 왜 v0.2부터 접근성 권한을 안 쓰나요? 한국에서는 2025년 9월부터 구글이 인터넷으로 받은 앱 중
> 접근성·문자·알림 읽기 권한을 쓰는 앱의 설치를 자동으로 막아요(사기 앱 대책).
> 그래서 위험한 권한을 빼고, 스크린타임 앱들이 쓰는 "사용 정보 접근"으로 바꿨어요.

## 처음 한 번만: 권한 2개 켜기

| 권한 | 하는 일 |
|---|---|
| 사용 정보 접근 | 지금 어떤 앱이 켜졌는지만 알아요(화면 내용은 볼 수 없어요). |
| 다른 앱 위에 표시 | 막힌 앱 위에 잠금 화면을 띄워요. |

1. 공부 잠금 앱 첫 화면의 **사용 정보 접근 켜기** → 목록에서 **공부 잠금** → 켜기.
2. **다른 앱 위에 표시 켜기** → **공부 잠금** → 켜기.
3. 만약 켜지지 않고 **"제한된 설정"** 창이 뜨면: 첫 화면의 **앱 정보 열기** → 오른쪽 위 **⋮** → **제한된 설정 허용** → 다시 켜요.
4. 첫 화면에 ✅ "앱 막기 준비 완료"가 보이면 끝이에요.

집중하는 동안에는 알림창에 "🔒 집중 중" 알림이 떠 있어요. 이 알림이 있어야 폰이 감시 기능을 끄지 않아요.
알림 허용을 물으면 허용해 주세요(거절해도 차단은 돼요).

> 가끔 갤럭시가 배터리를 아끼려고 앱을 멈출 수 있어요. 잠금이 안 걸리면
> **설정 → 애플리케이션 → 공부 잠금 → 배터리 → 제한 없음**으로 바꿔 주세요.

## 설정

- **기다려서 풀 때 걸리는 시간**: 10·20·30·60분
- **설정 앱도 잠그기**: 켜면 집중하는 동안 설정 앱과 앱 삭제 창도 막혀요. 권한을 끄거나 앱을 지우는 꼼수를 막아 줘요.
- **AI 사진 판단(선택)**: Claude 키, Gemini 키 중 하나 또는 둘 다 넣을 수 있어요. 둘 다 있으면 Claude를 먼저 써요.

| | Claude | Gemini |
|---|---|---|
| 비용 | 충전한 만큼(최소 5달러). 사진 1장에 가벼운 모델 약 1원, 똑똑한 모델 약 20원 | 무료로 쓸 수 있음(하루 횟수 제한) |
| 사진 | AI 학습에 쓰지 않음 | 무료일 때는 구글의 AI 학습·사람 검토에 쓰일 수 있음 |
| 키 받는 곳 | console.anthropic.com | aistudio.google.com |

> 두 곳 모두 **만 18세 이상**만 키를 만들 수 있어서, 부모님이 만들어 주셔야 해요.
> 키는 이 기기 안에만 암호화해서 저장되고, 사진을 판단할 때만 그 회사로 보내져요. 키를 다른 사람에게 보여 주거나 인터넷에 올리지 마세요.
> Gemini를 쓸 때는 이름·얼굴이 사진에 나오지 않게 찍어 주세요.

## 알아 둘 점

- AI 키가 없으면 사진은 기록일 뿐 내용을 확인하지 않아요. 결국 스스로와의 약속을 도와주는 도구예요.
- AI도 틀릴 수 있어요. 억울하게 떨어지면 더 잘 보이게 다시 찍거나 '기다려서 풀기'를 쓰세요.
- "설정 앱도 잠그기"를 끈 상태에서는 권한을 직접 꺼서 풀 수 있어요.
- 폰을 다시 켜도 집중 중이었다면 잠금이 다시 걸려요.
- 만든 사람: 직접 쓰려고 만든 개인 앱이라 Play 스토어에는 없어요.

## 개발

- Kotlin, 안드로이드 기본 화면(라이브러리 최소). 사진 판단은 Anthropic Java SDK(`ClaudeCheck.kt`)와 Gemini REST(`GeminiCheck.kt`), 공통 기준·결과 읽기는 `AiCheck.kt`.
- 키 보관: `KeyBox.kt`(Android Keystore AES-GCM). 키는 코드·저장소에 없다.
- 차단: `WatchService`(포그라운드 서비스)가 0.6초마다 사용 기록(UsageStatsManager)으로 앞에 나온 앱을 확인하고 `BlockActivity`를 띄운다. 접근성 서비스는 쓰지 않는다.
- `app/src/test`에 AI 답 읽기 단위 테스트가 있어요.
- `main`이나 `claude/**` 브랜치에 푸시하면 GitHub Actions가 테스트 후 APK를 만들어요.
